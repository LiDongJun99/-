# 🎮 坦克大战 (Tank Battle)

经典坦克大战游戏，纯 HTML5 Canvas 实现，无需任何依赖，浏览器打开即玩！

## 🎯 游戏特性

- 🎨 **像素风格画面** — Canvas 手绘坦克、砖墙、钢墙和爆炸特效
- 🤖 **AI 敌人** — 3 个智能敌方坦克，自动寻路和射击
- 🧱 **可破坏地形** — 砖墙可被子弹摧毁，钢墙不可破坏
- 💥 **爆炸特效** — 击杀敌人和子弹撞击的粒子爆炸效果
- ❤️ **生命系统** — 3 条命，被击中或撞击敌人会扣血
- 🏆 **计分系统** — 击杀得分 + 存活时间奖励
- ⏸️ **暂停功能** — 按 P 键暂停/继续

## 🎮 操作方式

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` / `↑` `←` `↓` `→` | 移动坦克 |
| `空格键` | 发射子弹 |
| `P` | 暂停 / 继续 |

## 🚀 快速开始

1. 克隆仓库：
```bash
git clone https://github.com/<your-username>/tank-battle.git
```

2. 用浏览器打开 `index.html` 即可开始游戏

或者直接双击 `index.html` 文件在浏览器中打开。

## 🛠️ 技术栈

- HTML5 Canvas
- 纯 JavaScript（无框架/无依赖）
- CSS3
